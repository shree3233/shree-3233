---

1. Import Libraries
import pandas as pd
import numpy as np

- pandas (pd): For data handling and DataFrame operations.
- numpy (np): For numerical computations like mean, standard deviation, etc.

from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

- train_test_split: Splits data into training and testing sets.
- LinearRegression: A model class for Linear Regression.
- mean_squared_error: Used to measure how accurate our predictions are.

---

2. Load Dataset
df = pd.read_csv("C:/Users/swara/Downloads/boston_housing_large.csv")

- Loads the Boston Housing dataset into a DataFrame df from the specified path.

df

- Displays the DataFrame.

df.columns

- Lists all the column names in the dataset.

---

3. Select Features and Target
x = df[['CRIM', 'ZN', 'INDUS', 'CHAS', 'NOX', 'RM', 'AGE', 'DIS', 'RAD', 'TAX',
       'PTRATIO', 'B', 'LSTAT']]

- Selects 13 feature columns and stores them in variable x.

y = df[['MEDV']]

- Selects the target column (MEDV - Median value of owner-occupied homes) and stores it in variable y.

---

4. Split Data into Training and Testing Sets
x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.25, random_state=42)

- Splits data:
  - 75% for training (x_train, y_train)
  - 25% for testing (x_test, y_test)
- random_state=42 ensures reproducibility.

---

5. Create and Train the Model
model = LinearRegression()

- Creates a Linear Regression model instance.

model.fit(x_train, y_train)

- Fits (trains) the model using the training data.

---

6. Predict on Test Data
y_pred = model.predict(x_test)

- Predicts the house prices for x_test (unseen data).

---

7. Evaluate the Model
model.score(x_train, y_train)

- Calculates and returns the R² score for the training set.
- R² measures how much variance in the target variable is explained by the model.

model.score(x_test, y_test)

- Calculates and returns the R² score for the test set (important for real-world performance).

np.sqrt(mean_squared_error(y_test, y_pred))

- Calculates the Root Mean Squared Error (RMSE) on the test set.
- RMSE gives an idea of how much error, on average, the model makes in its predictions.
